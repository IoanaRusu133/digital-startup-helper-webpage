# Digital Startup Helper - Webpage (DSH.ro)

A responsive landing page for a digital agency, built as a capstone project for Dr. Angela Yu's Udemy Bootcamp (Chapter 8: Advanced CSS). Showcases Box Model mastery, float-based layouts, and custom media queries.

## 🎓 Course Context
This project was developed as part of **"The Complete Full-Stack Web Development Bootcamp"** by **Dr. Angela Yu** on Udemy. It marks the completion of the **Advanced CSS** module.

## 🛠️ Features & Technical Skills
I applied the core concepts of CSS layout and design learned throughout the first 8 chapters:
* **Box Model Mastery**: Precise control over `margins`, `paddings`, and `borders`.
* **Advanced Layouts**: Used `float`, `display: inline-block`, and `vertical-align` to create a complex grid system.
* **Responsive Design**: Implemented custom **Media Queries** to ensure the site is mobile-friendly and adapts to various screen sizes.
* **Typography**: Integrated Google Fonts (*Google Sans*, *Manrope*) for a modern, professional look.
* **Navigation**: A functional header with links for *About us*, *Services*, and *Contact* (UI demo only).



## 📱 Responsiveness
The webpage is designed to be fully fluid:
1. **Desktop (> 900px)**: A 2-column service grid with images aligned to the side of the text.
2. **Mobile/Tablet (< 900px)**: Elements stack vertically, images move above the text, and widths adjust to 100% for better readability.



## 🚀 How to view
1. Clone this repository.
2. Open `index.html` in your browser.
3. Resize the browser window to see the responsive layout in action!
